# 🎉 Lucky Play — 사다리타기

모바일과 PC에서 사용할 수 있는 무료 사다리타기 게임입니다.

## 사용 방법
1. 참여 인원(2~24명)과 당첨 인원(1~참여 인원)을 설정합니다.
2. 번호 모드 또는 이름 입력 모드를 선택합니다.
3. 사다리 위 참여자를 선택하고 **사다리 시작**을 클릭합니다.
4. 경로 애니메이션과 당첨 결과를 확인하거나 전체 결과를 공개합니다.

## 특징
- 무작위 사다리 연결선 및 도착 위치 생성
- 실제 사다리 경로를 이용한 당첨자 판정
- Web Crypto API 기반 난수
- 반응형 디자인, 애니메이션, 축하 효과
- 서버 및 데이터베이스 불필요
- 이름은 브라우저에서만 처리
